# Headless contract-first OOP sample

Generated by `tools/generate_project.py` from the reusable OOP template.
`GENERATION.json` records the template commit and the SHA-256 of every
generated file. `config/project.json` holds this project's own fresh identity.

## Quickstart

Python 3.11+ (3.12+ on Windows if you use the template's workflow tooling).
Only `pytest` is needed, and only for the tests.

```
python main.py --mock process demo demo1234 1 2 3 10   # in-memory, pre-seeded demo user
python main.py register alice "correct horse"          # SQLite in ./app.db
python main.py process alice "correct horse" 4 5 6
python main.py history alice "correct horse" --limit 5

python -m pytest                                       # everything
python -m pytest -k mock tests/test_contract_auth.py tests/test_contract_data.py
python -m pytest -k sql  tests/test_contract_auth.py tests/test_contract_data.py
python tools/validate_boundaries.py
```

Passwords on the command line are a demo convenience; they appear in shell history.

## Layers

| Path             | Role                                                    | May import                         |
| ---------------- | ------------------------------------------------------- | ---------------------------------- |
| `contracts/`     | Typed ABCs, frozen dataclasses, exceptions              | stdlib only                        |
| `src/features/`  | SQLite (`auth.py`, `data.py`) and in-memory (`in_memory.py`) implementations | `contracts`, stdlib I/O |
| `src/cli/`       | Parse arguments, call one interface method, render      | `contracts`, `src.cli`             |
| `src/container/` | Composition root: builds and injects implementations    | anything except UI toolkits        |
| `tests/`         | Shared behavior tests run against every implementation  | anything                           |

`tools/validate_boundaries.py` enforces these rules and runs inside `pytest`.

## Rules

1. Change the contract first. A new parameter, return field or exception goes
   into `contracts/` before any implementation uses it.
2. The CLI never does work: no SQL, file I/O or computation.
3. Features never format for display; they return frozen dataclasses or raise
   a `contracts` exception.
4. Every public class in `src/features/` subclasses a `contracts` ABC.
5. No work at import time. Construction happens in `src/container/`.
6. Every implementation passes `tests/test_contract_*`. Register a new one in
   `IMPLEMENTATIONS` in `tests/conftest.py`.
7. Timestamps are timezone-aware UTC.
