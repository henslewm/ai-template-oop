# ChatGPT Connector Setup

## Default

- GitHub: connect `henslewm/ai-template-oop`.
- Web search: use for current public facts and primary sources, such as library or platform documentation.

## Add only when relevant

- Google Drive or uploaded files: owner documents a task names that are not in the repository.

This repository needs no mail, calendar or contacts connector; add one only when the owner names a task that requires it.

## Permission posture

Start read-only. A connector's availability is not permission to push, merge, delete or rename branches, open pull requests, edit issues, send, publish, or change sharing. Consequential writes require an explicit request in the current task.
